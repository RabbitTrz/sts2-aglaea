========================================================================
 Aglaea mod · ID 速查表
 （控制台里 `card <ID>` / `power <ID> <数量> <目标>` / `relic add <ID>` 用）
========================================================================

【三种查 ID 的办法】
  1. 游戏内控制台直接**按 Tab 补全**：输入 `card ` 后按 Tab，会列出所有卡牌 ID，
     继续打几个字母还能过滤（例：`card MOENEGIMOD-AGLAEA_GO` + Tab）。
     `power` / `relic` / `potion` / `fight` 等指令同样支持补全。
  2. 控制台输 `dump` → 把**全部** Model ID 输出到控制台并写进日志
     （包括原版的卡/能力/遗物，日志里搜 "DUMP" 或翻到末尾）。
  3. 直接看本文件（只列本 mod 的内容）。

  注意：个别**已停用**的内容（比如复缕）保留了文案、仍在表里，
  但代码里已注释掉，控制台用它会提示找不到——属正常现象。
